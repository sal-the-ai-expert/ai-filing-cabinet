# File routing

| Extension | Folder |
|-----------|--------|
| .docx .md .txt | documents/ |
| .xlsx .csv | spreadsheets/ |
| .pptx | presentations/ |
| .pdf | pdfs/ |
| .png .jpg .svg .gif | designs/ |
| .py .js .ts .sh | code/ |
| anything else | exports/ |

Path pattern: `projects/<slug>/<type>/YYYYMMDD-name.ext`

Do not invent other subfolders (no drafts/, old/, v2/). Show versions in the file name.
If the slug is unknown, ask.
